# Gordan Aleksandrovski — Portfolio

Bilingual (EN/MK) single-page portfolio, live at [gordanaleksandrovski.com](https://gordanaleksandrovski.com). Next.js 16, React 19, TypeScript, Tailwind CSS v4.

## Quick start

```bash
pnpm install
pnpm dev
```

`pnpm build` builds for production, `pnpm lint` runs ESLint.
